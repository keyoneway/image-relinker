# Image Relinker 0.1.1 发布设计

## 目标

发布不改变插件功能的 `0.1.1`，并在公开 README 中提供完整中文使用说明。

## 变更范围

- README 保留英文内容，新增中文章节：适用场景、安装、使用步骤、安全规则与无法自动修复时的处理方式。
- `manifest.json`、`package.json` 和 `package-lock.json` 的项目版本由 `0.1.0` 更新为 `0.1.1`。
- 构建 `main.js`，并作为 GitHub Release `0.1.1` 资产发布，连同 `manifest.json` 和 `styles.css`。

## 非目标

- 不改变图片扫描、匹配或写入逻辑。
- 不移除现有英文 README 内容。
- 不重新提交 Community Directory 条目。

## 验证

运行 `npm test`、`npm run check`、`npm run build`。确认 Release tag、manifest 版本和 package 版本均为 `0.1.1`，且 Release 包含三个指定资产。

## 发布

提交到 `main`，推送到 `origin`，创建公开 GitHub Release `0.1.1`。Community Directory 将自动检查该新 Release。
