# Image Relinker 0.1.2 回调告警修复设计

## 目标

消除 Community Directory 对 `src/main.ts:118` 的回调返回值警告，同时保持附件目录下拉选项的行为不变。

## 根因

`folders.forEach((path) => dropdown.addOption(path, path))` 隐式返回了 `addOption` 的链式返回值。目录扫描器要求 `forEach` 回调返回 `void`，因此报告该问题。

## 变更

将该表达式回调替换为带块体的回调，在块体内调用 `dropdown.addOption(path, path)`，使回调显式返回 `void`。

## 范围与验证

- 只修改 `src/main.ts` 中附件目录下拉选项的单行回调。
- 将版本更新为 `0.1.2`，同步 package、lockfile 与 manifest。
- 运行测试、TypeScript 检查和构建；发布带 `main.js`、`manifest.json`、`styles.css` 的 GitHub Release `0.1.2`。
- 不改变扫描、匹配、文件写入或 UI 文案。
